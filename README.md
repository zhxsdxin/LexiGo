# LexiGo

极简日语单词学习网站。零依赖、无构建步骤，双击 `index.html` 即可使用。

## 运行方式

**方式一：直接打开（最简单）**

双击 `index.html`，或拖进浏览器窗口。所有功能均可用，学习记录保存在浏览器本地。

**方式二：本地静态服务器（推荐用于手机测试）**

```bash
cd LexiGo
python3 -m http.server 8848
```

然后访问 `http://127.0.0.1:8848`。手机与电脑在同一 WiFi 下时，把 `127.0.0.1` 换成电脑的局域网 IP 即可在手机上访问。

浏览器要求：Chrome / Safari / Edge / Firefox 的近两年版本。

## 使用说明

### 学习（默认首页）

卡片可以左右翻转，两个面分别是：

- **正面** — 日语单词 + 音调
- **背面** — 读音假名 + 词性 + 中文释义（词库中有例句时一并显示）

**「认识 / 不认识」常驻在卡片下方，不需要先翻面。**

1. 先在心里回忆这个单词的意思。
2. 三种操作：
   - **认识** → 直接跳到下一个词，熟练度升级，下次复习间隔自动拉长。
   - **不认识** → 卡片翻到背面展示答案，同时该词进入错词复习队列。
   - **点击卡片 / 空格** → 手动翻面看答案，或从背面翻回正面。
3. 底部可切换上一词 / 下一词，右下角图标切换随机顺序。
4. 底部计数器本身就是词表入口，点击展开本组全部单词，点条目直接跳转。

快捷键：`空格` 翻转卡片 · `←` `→` 切换词 · `R` 发音 · `1` `2` `3` 切换标签页

### 复习

自动收集学习时标记为「不认识」的词，按熟练度从低到高排队。卡片翻转与按钮逻辑与学习页一致。

- **认识** → 从本轮队列移出，间隔按 10 分钟 → 1 天 → 3 天 → 7 天逐级拉长。
- **不认识** → 打回最基础等级，本轮内隔 2 个词再考一次，同时翻面展示答案。
- 底部计数器展开可看到本轮全部待复习词及其熟练度，点条目直接跳转。
- 没有到期的错词时显示完成状态，点「重新开始一轮」可召回所有未掌握的词。

### 进度

- 今日已学习词数、认识 / 不认识分布与命中率
- 词库整体学习进度
- 掌握程度分布（未掌握 → 牢固 五档）
- 待复习错词数量与需要多看几眼的词清单

底部「清空学习记录」需点击两次确认。

## 词库

内置 5 个词，位于 `assets/js/data/wordbank.js`。新增词只需往 `words` 数组里加一条：

```js
{
  id: 'w6',            // 唯一编号，不重复
  word: '飲む',        // 日语表记字
  kana: 'のむ',        // 读音假名
  pitch: 2,            // 音调番号 0-4，可为 null
  pos: '动词',          // 词性，可为 null
  meaning: '喝',       // 中文释义
  marker: null,        // 原始资料标记位，仅存档不展示
  example: null        // 例句，可为 null
}
```

`pitch` 为 0–4 时，界面显示对应的带圈数字（⓪ ① ② ③ ④）；为 `null` 时不显示音调。当前内置词库的音调依次为 味⓪ / 明日⓪ / 焦る② / 遊ぶ⓪ / 新しい④。

> 显示字符在 `wordbank.js` 的 `PITCH_MARK` 里用 Unicode 转义写死，不要直接改成形近字符。
> 带圈零 ⓪ 是 `U+24EA`，而 1–4 必须用 `U+2460–U+2463`（①②③④）。
> 看似对应的 `U+24EB–24EE`（⓫⓬⓭⓮）在 Unicode 里其实是「黑圈拉丁小写字母 b/c/d/e」，
> macOS 字体会把它们渲染成黑底白字的字母，显示完全错误，只有音调 0 那格碰巧正常。

`example` 为对象时形如 `{ jp: '水を飲みます。', cn: '喝水。' }`，为 `null` 时界面自动隐藏例句区域，不会显示空白占位。词性、假名、音调同样遵循「有则展示、无则隐藏」。

## 目录结构

```
LexiGo/
├── index.html
└── assets/
    ├── css/
    │   ├── base.css         设计变量、基础样式、hidden 兜底
    │   ├── layout.css       页面骨架、标签栏、视图切换
    │   └── components.css   单词卡、按钮、进度面板
    └── js/
        ├── data/wordbank.js 词库数据（唯一数据源）
        ├── core/
        │   ├── store.js     localStorage 读写、跨天结算、数据迁移
        │   ├── srs.js       Leitner 复习调度
        │   ├── stats.js     进度统计
        │   └── speech.js    日语发音（Speech Synthesis 封装）
        ├── ui/
        │   ├── card.js       单词卡组件（正反面翻转，学习与复习共用）
        │   └── picker.js     词表选择框
        ├── views/           study / review / progress 三个视图
        └── app.js           状态加载、标签切换、全局键盘
```

数据、逻辑、视图三层分离：换词库只动 `wordbank.js`，改复习节奏只动 `srs.js`。

## 数据存储

学习记录保存在浏览器 `localStorage` 的 `lexigo.state.v1` 键下，不上传服务器，换设备不同步。

- 只保留最近 30 天的每日统计，避免存储无限增长。
- 浏览器禁用存储（隐私模式）时自动降级为内存态，页面功能不受影响，进度页会提示记录不会保留。
- 本地数据损坏或版本升级缺字段时会自动重置为初始状态，不会导致页面白屏。

## 已验证项

在 Chromium 上完成 151 项自动化检查，全部通过：

- 音调字符专项（16 项）：pitch 0–4 的显示码位逐个断言、正反面一致、无黑圈字母污染
- 翻转卡片专项（56 项）：按钮常驻、点击/空格双向翻转、认识直接跳词、不认识翻面并入队、词表选择框跳转与收起、复习页同套交互、进度页中文对齐、移动端与 reduced-motion
- 学习流程回归（60 项）：错词入队 → 熟练度升级 → 复习答对出队 / 答错回插 → 完成状态 → 刷新恢复 → 随机顺序 → 桌面与移动端布局
- 降级（13 项）：禁用 localStorage、无语音 API、损坏 JSON、残缺旧数据、快速连点、清空数据均不影响核心功能
- `file://` 直接打开（6 项）：样式加载、翻面、错词入队、刷新保留记录均正常
- 进度页中文释义左边缘对齐：实测各行左边缘坐标完全一致
- 无障碍：`prefers-reduced-motion` 下过渡关闭（功能不受影响），键盘可完成全部操作

发音依赖系统日语语音包。macOS 与 iOS 自带，Windows 需在「设置 → 时间和语言 → 语音」中添加日语；没有语音包时发音按钮显示为「发音不可用」并禁用，其余功能不受影响。
